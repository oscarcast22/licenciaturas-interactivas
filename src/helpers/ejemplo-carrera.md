Este es un archivo markdown destinado a la creación de nuevos programas académicos dentro de las carpetas de colección ubicadas en src/content (Licenciaturas, Maestrías o Doctorados). Cada archivo contendrá los siguientes elementos:

- Título: El título del programa académico.
- Portada: Una imagen representativa del programa.
- Portada_alt: Texto alternativo de la imagen para mejorar la accesibilidad, el CEO y facilitar la identificación de animaciones de transición en el código. Este texto debe ser único para evitar conflictos con las animaciones de transicion entre paginas.
- Color: Un código de color que se utilizará para estilizar los componentes de las plantillas de la colección.
- Resumen: Una breve descripción del programa.
- Plan de estudios: Una estructura que contiene bloques (titulo) y nombres de unidades curriculares (contenido).
- Después de la sección marcada con tres guiones (---), se añade el perfil de egreso del programa, es donde esta escrito este texto.
