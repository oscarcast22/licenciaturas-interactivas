Este es un archivo Markdown destinado a la creación de nuevos programas académicos dentro de la colección de Licenciaturas. Cada archivo contendrá los siguientes elementos:

- Título: El título del programa académico.
- Portada: Una imagen representativa del programa.
- Portada_alt: Texto alternativo de la imagen para mejorar la accesibilidad y facilitar la identificación de animaciones de transición en el código. Este texto debe ser único para evitar conflictos con las animaciones de transición entre páginas.
- Color: Un código de color que se utilizará para estilizar los componentes de las plantillas de la colección.
- RVOE: El registro de validez oficial del programa.
- Resumen: Una breve descripción del programa.
- Plan de estudios: Una estructura que contiene bloques (titulo) y nombres de unidades curriculares (contenido).
- Después de la sección marcada con tres guiones (---), se añade el perfil de egreso del programa, es donde esta escrito este texto.
